\noindent\textbf{1. General information:}
\begin{itemize}[leftmargin=0.8cm, label=\textbullet, itemsep=2pt, topsep=2pt]
    \item Project code: TSV2026-127.
    \item Project title: Food Recognition and Nutritional Value Estimation System using Deep Learning.
    \item Principal Student Investigator: Nguyen Huu Thanh Hoa; Class: DI23Z6A1; Major: Computer Science.
    \item Supervisor: Assoc. Prof. Dr. Nguyen Thai Nghe.
\end{itemize}

\vspace{0.3cm}
\noindent\textbf{2. Objectives:}
\begin{itemize}[leftmargin=0.8cm, label=\textbullet, itemsep=2pt, topsep=2pt]
    \item To build an intelligent system utilizing Deep Learning for accurate recognition of various food types from a single image.
    \item To integrate a standardized nutritional database with a Lightweight OCR model that extracts actual food weight from packaging labels, enabling the calculation of total nutritional values (Calories, Lipids, Sodium, Carbohydrates) of a meal.
    \item To develop automated medical rule-based algorithms to analyze, warn, and recommend suitable dietary choices for patients with obesity and hypertension via the NutriCare mobile application.
\end{itemize}

\vspace{0.3cm}
\noindent\textbf{3. Novelty and Creativity:}
\begin{itemize}[leftmargin=0.8cm, label=\textbullet, itemsep=2pt, topsep=2pt]
    \item Simultaneously combines a deep learning food classification model (EfficientNetB0) with an object detection model (YOLOv8) and Lightweight OCR to automate the estimation of portion size directly from real-world food tray labels.
    \item Constructs a specific nutritional database for Vietnamese cuisine, strictly aligned with the National Institute of Nutrition's standards.
    \item Designs a medical Rule-based Engine at the backend capable of multi-index analysis and generating personalized pathological warnings in real-time without manual user input.
\end{itemize}

\vspace{0.3cm}
\noindent\textbf{4. Research Results:}
\begin{itemize}[leftmargin=0.8cm, label=\textbullet, itemsep=2pt, topsep=2pt]
    \item Successfully collected and annotated a dataset of Vietnamese food images with nutritional tags and a dataset of food tray price/weight labels for OCR training.
    \item Trained and optimized the YOLO model for label localization and the EfficientNet model for food classification, achieving high accuracy and real-time response on mobile environments.
    \item Fully implemented a Backend API service handling a multi-threading pipeline (image processing, OCR extraction, nutritional lookup, and medical rule checking).
    \item Successfully developed a prototype of the NutriCare mobile application supporting health profile management, food image capturing, and visual nutritional analysis.
\end{itemize}

\vspace{0.3cm}
\noindent\textbf{5. Products:}
\begin{itemize}[leftmargin=0.8cm, label=\textbullet, itemsep=2pt, topsep=2pt]
    \item The complete NutriCare mobile application (Android/iOS platforms).
    \item Weight files of the trained Deep Learning food recognition model, YOLO, and Lightweight OCR.
    \item Source code of the Backend API and the integrated medical-nutritional database.
    \item Project summary report, technical documents, bulletin, and an introduction video clip (as per Can Tho University's regulations).
\end{itemize}

\noindent\textbf{7. Contributions and Applicability:}
\begin{itemize}[leftmargin=0.8cm, label=\textbullet, itemsep=2pt, topsep=2pt]
